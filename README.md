# Walmart Sales Analysis

## Project Overview

This project explores weekly Walmart sales data using Python. The analysis focuses on one selected Walmart store and examines its sales patterns over time.

## Objectives

- Explore the structure of the sales dataset
- Calculate descriptive statistics
- Analyze weekly sales over time
- Identify unusually high and low sales weeks
- Interpret the findings from a business perspective

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Analysis

The analysis includes:

1. Loading and filtering the Walmart dataset
2. Exploring the dataset structure and data types
3. Calculating summary statistics
4. Visualizing weekly sales trends
5. Identifying the highest and lowest sales weeks
6. Examining holiday weeks and unusual sales patterns

## Key Findings

The selected store shows considerable week-to-week variation in sales.

The analysis identified a highest weekly sales value of approximately **674,919** and a lowest value of approximately **428,954**. Both occurred during holiday weeks. However, holiday weeks did not consistently result in higher sales.
